# Ecommerce-EDA-Analysis


## Project Overview
This project focuses on Exploratory Data Analysis (EDA) using Python on an e-commerce dataset.

## Objectives
- Understand dataset structure
- Analyze numerical and categorical features
- Detect skewness and distributions
- Generate visual insights

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Analysis Performed
- Dataset overview
- Missing values analysis
- Feature distribution analysis
- Skewness detection
- Categorical analysis
- Visualization using histograms and plots

## Files Included
- DecodeLabs_Week1.ipynb
- Dataset for Data Analytics.xlsx
